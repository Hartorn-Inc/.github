# Security Policy

This policy applies to every `Hartorn-Inc` repository that does not define its own `SECURITY.md`.

## Reporting a Vulnerability

Do not open a public issue, discussion, or pull request for security vulnerabilities.

Report vulnerabilities privately through GitHub Private Vulnerability Reporting on the affected repository (**Security** tab -> **Report a vulnerability**).

Please include:

- the affected repository, package, and version, tag, or commit SHA;
- a clear description of the vulnerability and its impact;
- minimal reproduction steps.

## Supported Versions

Unless stated otherwise in a repository, only the latest release receives security fixes.
